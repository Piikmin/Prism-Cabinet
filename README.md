# Prism Cabinet

## Concept

Prism Cabinet est un plugin Dalamud qui transforme votre bibliothèque de mods Penumbra en espace de test et d'organisation, directement dans le jeu.

## Installation

1. Ouvrez les réglages de Dalamud avec `/xlsettings`.
2. Ajoutez ce dépôt dans les **dépôts de plugins personnalisés** :

   ```text
   https://raw.githubusercontent.com/Piikmin/Prism-Cabinet/master/repo.json
   ```

3. Activez l'affichage des plugins de test, recherchez **Prism Cabinet**, puis installez-le.

## Ce que ça fait

- Tester rapidement un mod sur votre personnage sans modifier durablement votre configuration.
- Choisir les options d'un mod et vérifier ses prérequis.
- Tester des équipements, des apparences et des animations.
- Restaurer facilement votre apparence après un test.
- Trier vos mods par créateur, par nature ou selon les deux critères.
- Prévisualiser les changements avant de les appliquer.
- Rechercher les doublons et nettoyer les dossiers devenus vides.

## Commande

Ouvrez ou fermez Prism Cabinet avec :

```text
/prism
```

## Prérequis

- Penumbra est nécessaire.
- Glamourer est nécessaire pour l'équipement automatique et la restauration des apparences.

## Limites connues

- Un seul mod principal peut être testé à la fois.
- Les tests concernent uniquement votre personnage local.
- La reconnaissance des animations dépend des informations fournies par les mods.
- Certaines apparences nécessitent Glamourer pour être restaurées correctement.
- Le tri modifie durablement l'organisation des mods dans Penumbra.
